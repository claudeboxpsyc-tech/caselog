      Sync with your other device

      Sync isn't set up in this copy of Case Log yet: its relay address is missing (see SETUP.md).

      Pair your phone and computer once; after that every case you save on one shows up on the other. Cases are encrypted on the device with a key only your devices have. The sync service can't read them.

      On the first device, tap Set up sync. On the second, tap Pair with my other device and scan the code the first one shows.

      The pairing code opens your whole log. Show it only to pair your own devices.

      Backup and import

      Your paired devices are copies of each other. A CSV file is your own extra copy, and imports cases logged somewhere else, such as the NAS version of Case Log.

      Columns: date, procedure, category, role, approach, record_no, initials, age, attending, site, notes, also. One row per operation. Category uses the keys in a backup file, role is primary or assistant, and also lists other procedures done in the same operation, separated by |. Cases already in the log are skipped.

      Add to your home screen

      iPhone: open this page in Safari, tap Share, then Add to Home Screen, and always open Case Log from that icon: Safari can clear data of sites that aren't on the home screen. Android: open the browser menu and tap Add to Home screen or Install app. Computer: Chrome and Edge offer an install button in the address bar.
